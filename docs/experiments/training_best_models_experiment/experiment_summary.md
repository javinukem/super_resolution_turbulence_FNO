# Training Best Models Experiment

## Overview

This experiment trains the best-performing model from each architecture family
(**CFNO** and **EDSR**) from scratch on the **last snapshot only** (snapshot 79)
of each simulation, using the simulation-level train/validation split.

The goal is to produce comparable, cleanly trained models for the final
benchmark evaluation, using only statistically-stationary turbulence snapshots
(no transient/spinup data).

---

## Training Setup

| Setting             | Value                        |
|---------------------|------------------------------|
| **Optimizer**       | AdamW (lr=0.0002, weight_decay=1e-4) |
| **Loss**            | MSE                          |
| **Epochs**          | 100                          |
| **Batch size**      | 2                            |
| **AMP**             | Enabled                      |
| **Noise augmentation** | Gaussian, σ=0.01 on LR input |
| **Snapshot**        | Last only (index 79)         |

### Data

- **Training**: `/export/scratch/jalegria/full_states_h5/full_states.h5`
  with `snapshot_index=79` → 400 samples (one per training simulation)
- **Validation**: `/export/scratch/jalegria/full_states_h5/full_states_val.h5`
  with `snapshot_index=79` → 100 samples (one per validation simulation)
- Split generated by `data/split_dataset.py` (simulation-level 80/20 split)

### Memory Management

Models are trained **sequentially** — each model is fully trained, its artifacts
saved, and then deleted from GPU memory (`del model` + `gc.collect()` +
`torch.cuda.empty_cache()`) before the next model is loaded. Each training is
wrapped in a `try/except` so a failure in one model does not prevent the others
from training.

## Usage
